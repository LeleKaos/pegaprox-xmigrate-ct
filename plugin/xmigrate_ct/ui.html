XMigrate CT

Migrazione di container LXC tra cluster (anche privilegiati) via backup/restore come root. Lo script gira sul server PegaProx e si collega ai nodi in SSH.

Destinazione
Storage destinazione vuoto: si usa quello del CT d'origine se esiste anche sulla destinazione; se la destinazione ne ha più d'uno e quello non c'è, va indicato. Senza un terminale lo script non può chiederlo.
Chiave SSH del plugin

Il plugin usa una chiave propria. La chiave pubblica deve essere in ~/.ssh/authorized_keys di root su entrambi i nodi.
